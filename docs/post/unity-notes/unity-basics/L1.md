# Unity 入门 Day1 - 认识界面与创建第一个场景

## 一、Unity 界面分区
刚打开 Unity 时，界面主要分为这几个区域，记下来就不会迷路啦：

1.  **Hierarchy（层级面板）**
    显示当前场景里的所有游戏对象（比如相机、灯光、玩家角色），你可以在这里选中、创建、删除对象。

2.  **Project（项目面板）**
    你的“资源仓库”，脚本、图片、模型、场景文件都在这里，双击就能打开查看。

3.  **Inspector（检视面板）**
    选中对象后，这里会显示它的所有组件和属性，比如位置、缩放、脚本参数，都可以直接在这里修改。

4.  **Scene & Game 视图**
    - Scene：编辑模式，用来摆放对象、调整场景布局
    - Game：运行模式，点击运行按钮后，会在这里看到游戏的实际效果

---

## 二、创建第一个空场景
跟着这几步操作，就能创建一个干净的新场景：

1.  顶部菜单栏选择 `File → New Scene`
2.  选择 `Basic (Built-in Render Pipeline)`，点击 `Create`
3.  场景创建好后，按 `Ctrl + S` 保存，命名为 `Day1-FirstScene.unity`，存在 `Assets/Scenes` 文件夹里

---

## 三、给场景添加第一个对象：地板
接下来给场景加个“地板”，方便后续放东西：

1.  在 Hierarchy 面板右键 → `3D Object → Plane`
2.  在 Inspector 面板调整它的 Scale：
    - X: 10
    - Y: 1
    - Z: 10
3.  这样一个10x10的地面就做好啦，把相机往下挪一点，就能看到完整的地面了

---

## 四、今日踩坑记录
- 刚打开项目找不到 Project 面板？
  解决：顶部 `Window → General → Project` 就能重新调出来
- 运行游戏后场景里的东西乱飘？
  解决：检查对象的 Rigidbody 组件，如果不需要物理效果，直接删掉就行
