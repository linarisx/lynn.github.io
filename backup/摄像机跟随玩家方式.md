## 通过坐标的偏移位置计算
摄像机的移动需要写在LateUpdate
因为update和lateUpda之间有一些渲染动画要处理
```c#
public Transform target;
public float yOffect = -4;
public float zOffect = 7;
void LateUpdate()
{
      this.transform.position = target.position + target.forward * yOffect + target.up * zOffect;
      this.transform.LookAt(target);
}
```
